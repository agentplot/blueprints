# sounding

The design book for sounding, which works one question in one session
and ends on a conclusion the operator decides. Its chapters rest on
`design/capture/design.md`, "Questions: sounding", and cite Flywheel's
statement, `design/flywheel-next/requirements.md`, by clause number.
sounding's own statement is not written yet, so the book has no
appendix.

Build: `mdbook serve --open` here. Authoring rules: `CLAUDE.md` beside
this file.
