# eddy

The design book for eddy, the meetings tool of the capture design. Its
source is `design/capture/design.md`, "Meetings: eddy" and the contract
it prints. eddy has no statement of invariants yet, so the book has no
appendix; the chapters cite Flywheel's statement by clause number.

Build: `mdbook serve --open` here. Authoring rules: `CLAUDE.md` beside
this file.
