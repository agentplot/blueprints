# flume

The design book for flume, which launches one agent in one worktree
through a kind's stages and tidies the place when the work lands. Its
chapters rest on `design/capture/design.md`, "Launching: flume", and
cite crew's `teams` and `plan` rules, which flume takes over, by id.
flume's own statement is not written yet, so the book has no appendix.

Build: `mdbook serve --open` here. Authoring rules: `CLAUDE.md` beside
this file.
