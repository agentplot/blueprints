# Question: is a persona's unasked question evidence the intent was incomplete?

- **State:** open
- **Raised by:** the operator's structured feedback, 2026-08-07, section C4
- **Blocks:** nothing

## The question
A persona agent exercising a built application returns two kinds of
finding. One is a question or opportunity the intent does not cover, routed
back to the intent. Arguably the intent should have defined it already — so
is its appearance a signal the intent was incomplete?

## What turns on it
Whether these are counted and fed back as a measure of intent quality, or
only routed as findings. If counted, the design loop gets a feedback signal
it has none of today.

## What is already known
The routing is settled either way: a finding the intent is silent about is
a design question, and building it because an agent asked would let the
outer loop be written by the inner one.
