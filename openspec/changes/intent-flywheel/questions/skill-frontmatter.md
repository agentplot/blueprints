# Question: what can a skill declare in its frontmatter?

- **State:** closed → decisions/agent-profiles.md · sessions/2026-08-07-loop-layer/

- **Blocks:** nothing, but it simplifies the profile/skill pairing rules

## The question
Two answers wanted. Should some of these skills be forked rather than
shared? And can a skill declare its own agent type in frontmatter, rather
than a charge naming a profile and a skill separately?

## What turns on it
If a skill can name its agent type, the pairing rules in
`flywheel-inception` collapse and a charge names one thing instead of two.
It also bears on whether the session-type set needs twelve profiles or
twelve skills that carry their own.
