# Question: where does dispatch run?

- **State:** open — deferred out of this intent
- **Raised by:** the operator
- **Blocks:** nothing here

## The question
Dispatch runs on the workstation today. Moving it into the cloud — AWS
AgentCore named — would let it triage real-time inputs it has no path for
now: meeting transcripts, bug reports from users. The webhook receiver is
re-asked with it.

## What turns on it
Whether dispatch is a pane the operator can see or a service that reaches
him. It changes what the singleton is, not only where it runs.

## What is already known
Deferred deliberately: it becomes an ADR in `agentplot/flywheel` once that
repo carries the machinery. The repo now exists but the machinery has not
moved.
